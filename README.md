# شاخص بهمنش — Behmanesh Index

**چارچوب تحلیلی لایه‌به‌لایه و میان‌رشته‌ای برای تحلیل محتوای فکری و استخراج ساختار فکری**

---

## معرفی پروژه

**Behmanesh Index** یک روش‌شناسی سیستماتیک، لایه‌به‌لایه و مبتنی بر راستی‌آزمایی است که توسط محمدعلی بهمنش (@behmanesham) توسعه یافته است.

این چارچوب با هدف تحلیل عمیق محتوای فکری، استخراج الگوهای تکرارشونده، تم‌های محوری، تکامل فکری و جهان‌بینی افراد عمل می‌کند و قابلیت تعمیم‌پذیری بسیار بالایی در حوزه‌های مختلف دارد.

## ویژگی‌های کلیدی

- تحلیل لایه‌به‌لایه (Manifest → Latent → Meta)
- **وزن‌دهی زمانی دقیق با اولویت مطلق بلندمدت (۶۰٪)**
- راستی‌آزمایی اجباری و anchoring قوی به محتوای بلندمدت
- رویکرد واقع‌گرایانه-مکانیسمی و فاقد ایدئولوژی‌زدگی
- استفاده از Graph of Thoughts برای سنتز بهتر و کاهش خطا
- تمرکز بر عمق شرطی، تداوم ارجاعی و کیفیت کانونی

## نحوه استفاده (به‌روزرسانی شده)

1. **Methodology.md** را کامل مطالعه کنید (مبانی فلسفی).
2. **SOP_Intellectual_Content_Analysis_v3.3_Enhanced.md** را به دقت بخوانید و گام‌به‌گام اجرا کنید (این فایل اکنون **SOP اصلی و فعال** پروژه است).
3. **BEHMANESH_INDEX_PROMPT_v3.3.md** را به‌عنوان System Prompt (دستورالعمل اجرایی) استفاده کنید.
4. محتوای مورد نظر (با اولویت محتوای بلندمدت) را ارائه دهید.
