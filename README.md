# شاخص بهمنش (Behmanesh Index)

**چارچوب ارزیابی کیفی محتوای فکری**  
**نسخه ۳.۲**

---

### معرفی / About

**فارسی**  
شاخص بهمنش یک چارچوب تحلیلی پیشرفته برای ارزیابی **عمق فکری، انسجام بلندمدت، اصالت و کیفیت محتوای تحلیلی** در فضای دیجیتال فارسی است. این شاخص با تمرکز بر تمایز «متفکر» از «اپراتور توجه»، معیاری کیفی برای سنجش محتوای ارزشمند ارائه می‌دهد.

**English**  
The Behmanesh Index is an advanced qualitative framework for evaluating **intellectual depth, long-term coherence, authenticity, and analytical quality** of content in the Persian digital space. It distinguishes between genuine thinkers and attention operators.

**مالک معنوی / Intellectual Owner:** محمدعلی بهمنش (@behmanesham)  
**نسخه / Version:** ۳.۲  
**تاریخ آخرین به‌روزرسانی / Last Updated:** ۱۸ می ۲۰۲۶

---

### مفاهیم کلیدی / Core Concepts

- **متفکر در برابر اپراتور توجه** (Thinker vs Attention Operator)
- **عمق شرطی و پیش‌بینی‌کننده واقعی**
- **تداوم ارجاعی و انسجام بلندمدت** (Longitudinal Coherence)
- **استراتژی «کمتر اما عمیق‌تر»** (Productive Silence)
- **لایه اخلاقی انسانی اصیل**
- **استعاره‌سازی هوشمند چندلایه**
- **اجتناب از پوپولیسم و نمایش‌گرایی**
