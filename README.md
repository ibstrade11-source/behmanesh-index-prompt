# شاخص بهمنش — Behmanesh Index

**چارچوب تحلیلی لایه‌به‌لایه و میان‌رشته‌ای برای تحلیل محتوای فکری و استخراج ساختار فکری**

---

## معرفی پروژه

**Behmanesh Index** یک روش‌شناسی سیستماتیک، لایه‌به‌لایه و مبتنی بر راستی‌آزمایی است که توسط محمدعلی بهمنش (@behmanesham) توسعه یافته است.

این چارچوب با هدف تحلیل عمیق محتوای فکری، استخراج الگوهای تکرارشونده، تم‌های محوری، تکامل فکری، جهان‌بینی و مکانیسم‌های پنهان عمل می‌کند. شاخص بهمنش با ترکیب واقع‌گرایی مکانیسمی (Mechanistic Realism)، تحلیل Graph of Thoughts، Temporal Triangulation و رویکردهای میان‌رشته‌ای (از فلسفه علم، سیستم‌ها، معرفت‌شناسی و مطالعات گفتمان) طراحی شده و قابلیت تعمیم‌پذیری بسیار بالایی در حوزه‌های مختلف از علوم انسانی گرفته تا علوم پایه، اقتصاد، سیاست و هنر دارد.

این شاخص نه تنها کیفیت فکری را ارزیابی می‌کند، بلکه به کشف **مکانیسم‌های پنهان**، **پیش‌فرض‌های ضمنی**، **حلقه‌های بازخورد**، **نقاط اهرمی** و **تم‌های ساختاری** فکری کمک می‌کند و استانداردی برای تمایز بین تفکر ساختاریافته عمیق و محتوای سطحی/نمایشی ارائه می‌دهد.

## ویژگی‌های کلیدی

- تحلیل لایه‌به‌لایه (Manifest → Latent → Meta)
- شناسایی سیستماتیک تم‌ها (Themes Identification)
- وزن‌دهی سنگین به بلندمدت (حداقل ۶۰٪)
- رویکرد واقع‌گرایانه-مکانیسمی (Mechanistic Realism)
- فاقد ایدئولوژی‌زدگی و bias سیاسی
- استفاده از Graph of Thoughts برای سنتز بهتر
