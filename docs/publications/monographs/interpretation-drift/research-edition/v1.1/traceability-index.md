# Decision Traceability Index

## Objective

Decision Traceability measures whether every analytical conclusion can be traced back to explicit evidence within the original framework.

## Components

- Specification Reference
- Explicit Justification
- Intermediate Reasoning Preservation
- Evidence Mapping
- Reproducibility

## Scoring

0–100

Interpretation

90–100 Excellent

75–89 Good

50–74 Moderate

Below 50 Weak
