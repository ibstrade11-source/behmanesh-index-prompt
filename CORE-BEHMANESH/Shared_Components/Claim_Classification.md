# Claim Classification

**طبقه‌بندی اجباری تمام ادعاها در CORE_BEHMANESH v1.0**

- **[FACT]** → شواهد مستقیم، قابل検証، grounded در منبع
- **[INFERENCE]** → استنتاج منطقی با سطح اطمینان
- **[HYPOTHESIS]** → فرضیه قابل آزمون
- **[SPECULATION]** → گمانه‌زنی، نظر شخصی یا پیش‌بینی ضعیف

**قانون:** هر پاراگراف یا ادعای مهم باید یکی از این برچسب‌ها را داشته باشد.
