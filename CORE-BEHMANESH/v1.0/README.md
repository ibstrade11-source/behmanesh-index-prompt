# CORE-BEHMANESH

**لایه تقویت‌کننده رسمی و معماری متا شاخص بهمنش**

**نسخه:** v1.0  
**تاریخ انتشار:** ۲۸ می ۲۰۲۶  
**سازگار با:** Behmanesh Index v3.4 + BIO v1.0

این پوشه شامل چارچوب رسمی CORE_BEHMANESH است که کیفیت، شفافیت، rigor علمی و توضیح‌پذیری تحلیل‌های شاخص بهمنش را به طور قابل توجهی افزایش می‌دهد.

## ساختار پوشه

- `v1.0/` → سند اصلی معماری و پروتکل
- `Scientific_Modules/` → ماژول‌های تخصصی علمی (فیزیک، پزشکی، اقتصاد و غیره)
- `Shared_Components/` → اجزای مشترک (Claim Classification، Uncertainty، Fallacy Detection)

## هدف
ادغام اصول CORE_BEHMANESH v1.0 به عنوان Meta-Layer روی شاخص بهمنش برای استانداردسازی تحلیل‌ها.
